# LearninAppP2-group61

By clicking the Load button you can choose to import a random pre-written command program out of one of the following categories:
1. Basic
2. Advanced
3. Expert

You can also choose to import your own program by clicking on 'Import file'.

When clicking on 'Load Exercise' you can import a pathfinding exercise.

-----

When writing your own program in the text editor the commands should be spelled correctly and they are case-sensitive.

The available commands are:
- Move (amount of steps)
- Turn (Left/Right)
- Repeat (amount of times to be repeated) times
- RepeatUntil (WallAhead/GridEdge)
  
When nesting commands only please use tab or 4 spaces.
